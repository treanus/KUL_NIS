# search-string becomes the pattern dcm2bids matches SeriesDescription against
# (KUL_dcm2bids.sh). Unanchored by default, and anchors are supported:
#
#   str      ->  *str*     matches anywhere (the default)
#   ^str     ->  str*      description must START with str
#   str$     ->  *str      ... must END with str
#   ^str$    ->  str       ... must be exactly str
#
# Anchor whenever one description is a prefix or superstring of another: a
# series matching two entries is placed by NEITHER ("Several Pairing" in the
# dcm2bids log) and is lost with only a warning.
#
# mb and pe_dir are needed for PHILIPS only. KUL_dcm2bids.sh reads DICOM
# (0008,0070) and, for Siemens, takes them from the dcm2niix sidecar instead --
# the values in this file are then never read. Write "-" in both columns for
# Siemens rows so it is obvious they are not doing anything.
#
# Rows are grouped by scanner because the two sites name series differently.
# Both groups are always active: a row that matches nothing costs nothing, so
# one template covers both scanners.
